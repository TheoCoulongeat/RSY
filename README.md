# RSY Shipyard – Beyond the Waves

Official website of **RSY (Rodriguez Ship Yard)**, a Toulon shipyard that moulds and finishes composite hulls for boat dealers and boatbuilders.

Built for the Kalypso business game (SHS, SeaTech, November 2026) by team Kalypso 2.

## Content
- `index.html` – the whole site (one self-contained page)
- `logo.png` – RSY anchor logo
- `images/` – hull photos (Aramis, Porthos, Athos) and video posters
- `media/` – company film and hull advertisement (MP4, French & English subtitles)

## Publish with GitHub Pages
1. Push these files to the root of the repository's `main` branch.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. After about a minute the site is live at `https://<username>.github.io/<repository>/`.

No build step is needed: it is a static site.
